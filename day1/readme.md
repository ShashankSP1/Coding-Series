You are given an array of numbers. Write a JavaScript program to calculate the sum of all elements in that array.

Example 1:

Input:
[10, 20, 30, 40, 50]

Output:
150

Explanation:
10 + 20 + 30 + 40 + 50 = 150

Example 2:

Input:
[5, 10, 15]

Output:
30

Example 3:

Input:
[100]

Output:
100

What you need to understand
Before writing the code, think about these things:
1. How do you access individual elements of an array?
2. How can you visit every element in an array?
3. How can you store the running total?
4. When should the loop stop?
5. What should be the initial value of the sum?

Conditions:
- Use JavaScript.
- Try solving it using a for loop.
- Don't use the built-in reduce() method for this question.
- Your code should work for arrays of different lengths.
