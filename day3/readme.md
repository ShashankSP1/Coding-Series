You are given an array of numbers. Write a JavaScript function to find the smallest number in the array.

Example 1:

Input:
[10, 25, 5, 80, 45]

Output:
5

Example 2:

Input:
[-10, -5, -20, -2]

Output:
-20

Example 3:

Input:
[50, 30, 10, 5, 2]

Output:
2

Conditions
1. Use JavaScript.
2. Use a for loop.
3. Don't use Math.min().
4. Don't use .sort().
5. Assume the array contains at least one element.
