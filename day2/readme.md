Write a JavaScript program to find the largest number in the given array.

Return the largest number.
2. Examples
Example 1

Input:
[10, 25, 5, 80, 45]

Output:
80

Explanation: 80 is the largest number in the array.

Example 2

Input:
[12, 50, 100, 25, 75]

Output:
100

Example 3

Input:
[-10, -5, -20, -2]

Output:
-2

3. Understand the logic
Before writing code, think about these questions:
1. How can you access each element in an array?
2. How can you compare two numbers?
3. How can you keep track of the largest number found so far?
4. What happens when you find a number greater than your current largest number?
Hint: You need a variable that stores the largest number found so far. Update it whenever you find a bigger number.
4. Conditions
- Use JavaScript.
- Use a for loop.
- Don't use the built-in Math.max() method.
- Don't use .sort().
- Your solution should work with negative numbers too.
- Assume the input array contains at least one element.
