Write a JavaScript function that counts how many even and odd numbers are present in a given array.

Example:
const arr = [10, 15, 20, 25, 30, 35, 40];

Expected output:
Even numbers: 4
Odd numbers: 3

2. Requirements
1. Create a function named countEvenOdd.
2. Accept an array as an argument.
3. Use a for loop to iterate through the array.
4. Use the modulus operator (%) to check whether a number is even or odd.
5. Return both counts.
Hint:
- number % 2 === 0 means the number is even.
- Otherwise, it is odd.
